Escape from Limbo is a short text adventure game created for a group project for CSC 3102 (data structures) at LSU WAY back in Spring 2001 I think. Over the years I've made some small but IMO nice updates since we finished it back in the day. You can find prebuilt binaries in the `builds` folder though the Windows one is very very old. Hit up the `src` directory to build it yourself. It should build and run with any bog standard C compiler.
